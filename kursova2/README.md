# 📚 Litera — книжковий онлайн-магазин

Курсова робота: «Розробка веб-додатку для книжкового онлайн-магазину».

Повноцінний full-stack застосунок (MERN): каталог книг із пошуком, фільтрами
й пагінацією, кошик, авторизація (JWT), особистий кабінет із замовленнями та
адмін-панель для керування книгами й замовленнями.

## 🛠️ Технології

**Backend:** Node.js, Express, MongoDB (Atlas) + Mongoose, JWT (access/refresh),
bcryptjs, CORS, dotenv.
**Frontend:** React 19 + Vite, React Router, Tailwind CSS, Axios.

## 📂 Структура

```
kursova2/
├── backend/        # сервер Express + API + моделі Mongoose
│   ├── config/db.js
│   ├── controllers/   # auth, books, orders
│   ├── middleware/    # auth.js, adminOnly.js
│   ├── models/        # User, Book, Order
│   ├── routes/
│   ├── seedData.js    # наповнення бази 24 книгами
│   └── server.js
└── frontend/       # клієнт React (Vite)
    ├── public/images/books/   # локальні обкладинки книг (.jpg/.png)
    └── src/        # pages, components, context, api
```

## 🚀 Запуск

Потрібні **два термінали** (база MongoDB Atlas уже налаштована у `backend/.env`).

**1. Backend**
```bash
cd backend
npm install
npm run seed     # один раз — наповнити базу книгами та користувачами
npm run dev      # сервер на http://localhost:5000
```

**2. Frontend**
```bash
cd frontend
npm install
npm run dev      # клієнт на http://localhost:5173
```

Відкрити в браузері: **http://localhost:5173**

## 🖼️ Про обкладинки

Усі обкладинки — **реальні українські видання** — збережені локально в
`frontend/public/images/books/`, тому завжди завантажуються (без залежності від
зовнішніх сайтів). Шлях до картинки зберігається в полі `image` книги, напр.
`/images/books/duna.jpg`. Щоб додати книгу через адмінку з власною обкладинкою —
покладіть файл у цю теку і вкажіть такий самий шлях.
